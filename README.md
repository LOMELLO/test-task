# NHL: предсказание успешности команды в следующем сезоне

Выполненное отборочное задание «Специалист по работе с ИИ (FIN)»: сбор данных о командах NHL,
построение задачи классификации (target — попадание доли побед следующего сезона строго выше
медианы этого сезона), EDA, модели и итоговая оценка на отложенном тесте.

## Ключевые результаты (подробно — в ноутбуке)

- Данные: 582 строки, 35 команд, сезоны 1990–2011; сезон 2004 отсутствует (локаут);
  `ot_losses` пуст в 1990–1998 (224 строки); `win_rate` включает ничьие до 2004.
- Пар `t → t+1`: **516**; исключено 66 строк (60 — отсутствие будущего сезона, 6 — переименования команд);
  23 равенства будущей медиане → `target=0` по правилу «строго выше».
- Временной сплит по `target_year`: train ≤ 2005 (338 строк), validation 2006–2008 (89), test 2009–2011 (89).
- Ориентиры на validation: константа ROC-AUC 0.500; текущий `win_rate` — 0.757.
- Финальная модель (выбрана по validation до открытия теста): логистическая регрессия на 7 признаках
  сезона t в Pipeline (SimpleImputer → StandardScaler → LogisticRegression, `C=1.0`, `random_state=42`).
- **Test:** ROC-AUC **0.7538**, F1 @0.5 **0.6610**, accuracy @0.5 **0.5506** (ориентир `win_rate`:
  0.7404 / 0.6522 / 0.6404; константа: 0.5 / 0 / 0.5281).
- Сезонная нормировка признаков (эксперимент) результат не улучшила (0.7533), случайный лес — хуже (0.7229):
  сложность на этих данных преимущества не дала.
